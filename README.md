# NumPy for Linear Algebra & AI/ML Foundations

A hands-on repository containing Python implementations, benchmarks, and visualizations of core numerical computing and linear algebra concepts using **NumPy**. Built as part of an AI/ML engineering preparation roadmap focusing on first-principles mathematical rigor and high-performance data pipelines[cite: 2, 11].

---

## 📌 Overview

Understanding how **NumPy** (`ndarray`) works under the hood and how abstract mathematical concepts translate into vectorized code is essential for building scalable machine learning systems[cite: 1, 11]. This repository covers:
* **Performance & Memory Architecture:** Comparing contiguous C-level memory buffers and SIMD vectorization against standard Python lists.
* **Data & Vector Normalization:** Implementing feature scaling (Min-Max, Z-Score) and unit vector normalization from scratch.
* **Geometric Linear Algebra:** Translating visual concepts from *3Blue1Brown's Essence of Linear Algebra* and many more (vectors, linear transformations, determinants, dot/cross products, and eigenvalues) into code and Matplotlib visualizations[cite: 1, 3].
